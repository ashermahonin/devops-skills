Навыки можно установить вместе с небольшим каркасом проектной документации. Он нужен DevOps-агенту для быстрой ориентации без чтения всего репозитория.

| Файл | Назначение |
| --- | --- |
| `00-index.md` | Краткое описание проекта, владельцы, окружения и критически важные ссылки. |
| `01-inventory.md` | Сервисы, кластеры, аккаунты, провайдеры, реестры и CI-системы. |
| `02-access-and-secrets.md` | Модель доступа, хранилища секретов, ротация и заметки аудита. |
| `03-deployments.md` | Пути выкладки, правила релиза и команды отката. |
| `04-observability.md` | Метрики, журналы, трассировки, панели, оповещения и SLO. |
| `05-incidents.md` | Хронология инцидентов, решения по восстановлению и действия по профилактике. |

Держите эти файлы короткими: это навигационная память, а не копия репозитория. Полный контекст живёт в исходном коде и подключённом RAG или графе. Никогда не записывайте сюда действующие учётные данные, закрытые ключи, токены доступа или неочищенные эксплуатационные журналы.
