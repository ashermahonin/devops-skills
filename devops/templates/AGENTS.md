# DevOps Skills Project Rules

## Purpose

This project has DevOps skills installed for Codex-compatible agents.

## Required Workflow

1. Start broad DevOps, infrastructure, deployment, automation, security, or operations work with `devops-router`.
2. Route to the narrow skill that matches the domain.
3. Check current documentation before generating platform-specific configuration or commands.
4. Keep changes scoped and reversible.
5. End with verification steps, risks, rollback, and assumptions.

## Installed Skill Families

- Kubernetes operations
- Cloud operations
- Observability operations
- CI/CD automation
- Scripting automation
- Infrastructure as Code
- Container platforms
- Security and secrets
- Incident troubleshooting
- Network, VPN, and secure connectivity

## Local Routing

If present, use `.agents/routing/devops-skills.json` as the machine-readable routing table.
