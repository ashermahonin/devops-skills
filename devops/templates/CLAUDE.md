# DevOps Skills Project Rules

Claude Code should use the installed DevOps skills for infrastructure, operations, deployment, automation, security, and troubleshooting tasks.

Start with `devops-router`, then use the matching domain skill. Use Context7 MCP before platform-specific code, configuration, commands, provider resources, manifests, pipelines, scripts, or security controls. Apply the principal-level operating model before write-heavy work. Always include validation, risks, rollback, and assumptions when infrastructure behavior changes.
